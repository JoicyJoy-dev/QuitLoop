# QuitLoop API

.NET 10 Minimal API. Modular monolith, PostgreSQL, Dapper, Npgsql.

```bash
# Postgres must be running (docker compose up postgres)
dotnet run --project src/QuitLoop.Api
```

- http://localhost:5080
- http://localhost:5080/health

See [../../docs/getting-started.md](../../docs/getting-started.md).
